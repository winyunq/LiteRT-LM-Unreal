本地 AI 之魂

面向 UE 5.8 的本地推理插件：提供缺省单对话外观、独立多 Agent 记忆，以及通往 LiteRT-LM v0.14 官方完整 API 的原生 C++ 入口。

ABI 防火墙：零部署集成

当前 Win64 包将官方 litert-lm.dll 与小型扩展桥 litert_lm_wrapper.dll 分离。STL、Abseil 和 Protobuf 对象不会穿越 C ABI 边界；原生 C++ 开发者仍可通过随包 SDK 使用官方完整 API。

底层技术栈一瞥

GOOGLE LITERT WIN64 / ANDROID GPU STABLE C ABI 1.2 UE C++ / BLUEPRINT

统一的状态模型

Quick Chat 是普通缺省 Agent 的兼容外观。通过 Get Conversation 可继续使用记忆、工具和存档能力，不会丢失上下文。

记忆正确的多 Agent

每个 Agent 保有独立规范历史；共享模型与串行队列避免复制模型。当前 GPU 运行时需要时会从目标 Agent 的完整历史重建。

单对话与多对话

按照 UE 5.8 已核对的 Blueprint 与 C++ 步骤操作，理解 Quick Chat 的缺省 Conversation 语义，并正确隔离多个 NPC 的记忆。
