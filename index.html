Bring the Soul of Local AI
to Your Unreal Projects

A UE 5.8 local inference plugin with a default single-conversation facade, independent multi-Agent memory, and native C++ access to the official LiteRT-LM v0.14 API.

ABI Firewall: Zero-Deployment Integration

The current Win64 package separates the official litert-lm.dll from a small extension bridge, litert_lm_wrapper.dll. STL, Abseil, and Protobuf objects do not cross the C ABI boundary, while native C++ users can still access the complete official API through the shipped SDK surface.

One State Model

Quick Chat is a compatibility facade over an ordinary default-configured Agent. You can move to memory, tools, or persistence through Get Conversation without losing context.

Memory-Correct Multi-Agent

Each Agent owns an independent canonical history. One shared model and serial queue avoid model copies; cross-Agent switches rebuild from complete history when required by the current GPU runtime.

Single & Multiple Conversations

Follow the UE 5.8-verified Blueprint and C++ guide. It explains why Quick Chat is the default Conversation facade and how to keep independent NPC memories.
